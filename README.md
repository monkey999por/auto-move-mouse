# マウス自動円運動マクロ

Windows 11 用の PowerShell スクリプトです。起動時のカーソル位置を中心に円運動し、Esc、左右クリック、物理的なマウス移動のいずれかで停止します。クリックは自動実行しません。管理者権限や外部ライブラリは不要です。

## 起動

このフォルダーで PowerShell を開き、次を実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\mouse-circle.ps1
```

実行ポリシーの `Bypass` はこの起動プロセスにだけ適用されます。起動前に、円の中心にしたい位置へカーソルを置いてください。起動直後、カーソルは中心から半径分だけ右へ移動します。

## 停止

Esc キー、左クリック、右クリック、または物理的にマウスを動かします。停止理由がコンソールに表示されます。クリックは通常どおり対象アプリにも届き、停止後にカーソルを元の位置へ戻しません。

## 設定

`mouse-circle.ps1` 冒頭の次の値を編集します。

| 値 | 初期値 | 意味 |
| --- | ---: | --- |
| `$Radius` | 100 | 円の半径（px） |
| `$StepsPerCircle` | 120 | 1周の分割数 |
| `$IntervalMs` | 20 | 移動間隔（ms） |

初期設定では約 2.4 秒で 1 周します。円が画面の端を越える場合、カーソル位置はデスクトップ領域内に収まります。

## 停止条件の確認方法

1. 起動し、カーソルが継続して円運動することを確認します。自身の移動で止まらないことも確認します。
2. 再起動して Esc を押し、`停止理由: Escキー` を確認します。
3. 再起動して左クリックし、`停止理由: 左クリック` と通常のクリック動作を確認します。
4. 再起動して右クリックし、`停止理由: 右クリック` と通常のクリック動作を確認します。
5. 再起動してマウス本体を動かし、`停止理由: 物理的なマウス移動` を確認します。
6. 各停止後、カーソルが再び自動移動せず、開始位置へ戻されないことを確認します。

内部では Windows の低レベルマウス・キーボードフックで操作を受けます。自動移動は `SendInput` による注入イベントで、フックはその注入フラグを見て物理移動と区別します。フックは終了時とエラー発生時に解除します。Windows API の制約により、管理者権限で動作するアプリや保護された画面への入力は制限される場合があります。

## 検証状況

Windows PowerShell 5.1 で埋め込み C# コードのコンパイルを確認済みです。実機での円運動、Esc、左右クリック、物理移動による停止は未検証です。上記の手順で確認してください。
